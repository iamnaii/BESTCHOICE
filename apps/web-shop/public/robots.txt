# BESTCHOICE Online Shop — robots.txt
# Hybrid AI strategy: allow AI crawlers for marketing/SEO, block /api/* and aggressive scrapers
#
# ⚠️ /api/shop/share/:id คือหน้าการ์ดแชร์ (OG/JSON-LD) ที่ระบบสร้างลิงก์ไปหาเอง —
# มันอยู่ใต้ /api/ จึงโดน `Disallow: /api/` บล็อกไปด้วย ทำให้ crawler ที่เคารพ
# robots.txt (facebookexternalhit ฯลฯ) ดึงการ์ดของเราไม่ได้ ⇒ ต้อง Allow ก่อนทุกบล็อก
#
# ⚠️ รูปสินค้าอยู่ที่ /api/shop/products/:id/photos/:angle — ใต้ /api/ เช่นกัน ถ้าไม่ Allow
# crawler ทุกตัวดึงรูปสินค้าไม่ได้ (ไม่ขึ้นค้นรูป / ไม่มีรูปในผลค้นหา) ⇒ Allow ไว้ทุกกลุ่ม
# (เปิดเฉพาะ path รูป — JSON ของสินค้าที่ /api/shop/products ยังถูกบล็อกตามเดิม)
# ยกเว้นกลุ่ม CCBot — ดูหมายเหตุที่กลุ่มนั้น
#
# ⚠️ RFC 9309: บอทที่ match กลุ่มระบุชื่อจะอ่าน "เฉพาะกลุ่มตัวเอง" ไม่รวมกับกลุ่ม * —
# ทุกกลุ่มระบุชื่อจึงต้องมี Disallow ชุด user-flow (/apply /checkout /orders /account)
# ครบเหมือนกลุ่ม * เสมอ ไม่งั้นบอทนั้นเห็นหน้าที่เราไม่อยากให้ index

User-agent: *
Allow: /
Allow: /api/shop/share/
Allow: /api/shop/products/*/photos/
Disallow: /api/
Disallow: /apply
Disallow: /checkout
Disallow: /orders
Disallow: /account
