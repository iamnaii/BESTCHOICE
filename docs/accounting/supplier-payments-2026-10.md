# จ่ายเงินผู้จัดจำหน่าย / มัดจำ / เจ้าหนี้รายผู้จัดจำหน่าย (ก้อน 2 · ตุลาคม 2569)

ที่มา: คำตัดสินเจ้าของกิจการ 2026-10-05 และคำตอบฝ่ายบัญชี 2026-09-30 ข้อ 9 · 2026-10-05 ข้อ 1 และข้อ 4
("ให้โปรแกรมสร้างเมนูจ่ายเงินผู้จัดจำหน่าย และตัดสต๊อคให้เรียบร้อยก่อนใช้งานจริง")

## กติกา

- จ่ายเงินผู้จัดจำหน่าย **โอนธนาคารเท่านั้น** จากบัญชีธนาคารหน้าร้าน (จ่ายออก) `S11-1202` — ไม่มีเงินสด/เช็ค
- **สลิปบังคับ** ทุกครั้ง · วันที่โอนไม่เกินวันนี้ และย้อนหลังไม่เกิน 365 วัน
- ชนิดรายการโปรแกรมตัดสินจากฐานะในสมุดบัญชีของใบสั่งซื้อ:
  - มีเจ้าหนี้คงเหลือ (รับของแล้ว) → **ชำระค่าสินค้า** ไม่เกินเจ้าหนี้ · ส่วนที่จ่ายเกิน = มัดจำ รอหักตอนรับของที่เหลือ
  - ยังไม่มีเจ้าหนี้ → **มัดจำ** (`S11-4201`) · ถูกหักเข้าเจ้าหนี้อัตโนมัติตอนรับของ (หน่วยที่รอถ่ายรูปหักตอนผ่านเข้าคลัง)
- เพดาน: มัดจำ + ชำระ − มัดจำที่ได้คืน ≤ ยอดสุทธิของใบ
- งวดของวันโอนปิดแล้ว → ลงวันที่บันทึกแทน และสร้างงานแจ้งฝ่ายบัญชี (แท็ก `supplier-payment-period`)
- รายการที่บันทึกผิด: **เจ้าของ** ยกเลิกรายการ (ต้องมีเหตุผล) = กลับรายการเต็มจำนวนลงวันที่ที่กด · มัดจำที่ถูกหักเข้าเจ้าหนี้แล้วยกเลิกไม่ได้
- ยกเลิกใบสั่งซื้อที่มีมัดจำค้าง ต้องเลือก **ได้คืน** (เข้า `S11-1201` · ส่วนที่ได้คืนไม่ครบ → `S53-1105`) หรือ **ไม่ได้คืน** (→ `S53-1105`)
- สร้าง/อนุมัติใบสั่งซื้อ **ไม่รับยอดจ่าย** อีก · `PATCH /purchase-orders/:id/payment` ตอบ 410
- รับเข้าตรงจ่ายทันที: โอน + สลิป แล้วลงรายการใน transaction เดียวกับรับของ
- `PurchaseOrder.paidAmount` / `paymentStatus` = ผลรวมจากตาราง `purchase_order_payments` — ห้ามเขียนตรง

## รายการบัญชี (สมุดหน้าร้าน · ทุกใบติด `metadata.supplierId`)

| เหตุการณ์ | Dr | Cr |
|---|---|---|
| มัดจำก่อนรับของ | `S11-4201` เงินมัดจำจ่ายล่วงหน้า - ผู้จัดจำหน่าย | `S11-1202` |
| หักมัดจำเข้าเจ้าหนี้ (อัตโนมัติตอนรับของ) | `S21-1101` / `S21-1102` | `S11-4201` |
| ชำระค่าสินค้า | `S21-1101` / `S21-1102` | `S11-1202` |
| ยกเลิกใบ · ได้เงินมัดจำคืน | `S11-1201` (+ `S53-1105` ส่วนที่ได้คืนไม่ครบ) | `S11-4201` |
| ยกเลิกใบ · ไม่ได้คืน | `S53-1105` ค่าใช้จ่าย - มัดจำที่ไม่ได้คืน | `S11-4201` |
| ยกเลิกรายการที่บันทึกผิด | กลับรายการเดิม | |

บัญชีย่อยเจ้าหนี้ตามผู้ติดต่อ: ไม่เพิ่มรหัสในผัง — รายงาน `GET /purchase-orders/payables/ledger` จัดกลุ่มบรรทัด
`S21-1101` / `S21-1102` / `S11-4201` ตาม `supplierId` (รายการรับของก่อน 05/10/2569 ไม่มี supplierId → ย้อนจาก poId)

## Endpoint

| เส้นทาง | สิทธิ์ | หน้าที่ |
|---|---|---|
| `POST /purchase-orders/:id/payments` | OWNER, BRANCH_MANAGER | บันทึกการจ่าย `{ paidAt, amount, slipUrl, reference?, note? }` |
| `POST /purchase-orders/:id/payments/:paymentId/void` | OWNER | ยกเลิกรายการ `{ reason }` |
| `GET /purchase-orders/:id/payments` | + FINANCE_MANAGER, ACCOUNTANT | รายการจ่าย + ฐานะจากสมุดบัญชี |
| `GET /purchase-orders/payables/ledger?month=YYYY-MM` | + FINANCE_MANAGER, ACCOUNTANT | เจ้าหนี้รายผู้จัดจำหน่าย |
| `GET /purchase-orders/payables/ledger/:supplierId?month=` | + FINANCE_MANAGER, ACCOUNTANT | รายการเคลื่อนไหว |
| `POST /purchase-orders/:id/cancel` | OWNER, BRANCH_MANAGER | body `{ depositOutcome, refundedAt?, refundAmount?, slipUrl?, reason? }` เมื่อมีมัดจำค้าง |

## ยังไม่ทำ / รอ

- รายการจ่ายเก่าที่กรอกไว้ก่อนมีเมนู (คอลัมน์ `paidAmount` เดิม) ไม่ย้อนลงบัญชี — หน้าจอแสดงป้ายเตือน
- รหัสบัญชีย่อยในผัง (ถ้าฝ่ายบัญชีต้องการจริง) — รอคำตอบเอกสาร 05/10 ข้อ 4
- ก้อน 3 ตัดสต๊อก (หาย/เสียหาย/ตัดจำหน่าย) และก้อน 5 ภาษีซื้อของเครื่องขายผ่อน
