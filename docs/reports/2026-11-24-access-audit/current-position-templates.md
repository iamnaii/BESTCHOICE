# สิทธิ์ในแม่แบบตำแหน่งปัจจุบัน

นี่คือ DEFAULT_ACCESS_POSITIONS ใน source ไม่ใช่สิทธิ์ที่มอบหมายจริง และไม่ใช่ข้อเสนอฉบับใหม่ บริษัท/สาขา/เคสยังไม่ได้เลือก การมี permission เดี่ยวไม่รับประกันว่า workflow ใช้งานได้ สิทธิ์ที่ไม่อยู่ในแม่แบบไม่ถือว่าอนุญาต

## เจ้าของ (OWNER) — 0 สิทธิ์ที่ระบุในแม่แบบ

OWNER ใช้อำนาจเจ้าของแยกจากตำแหน่งที่มอบหมายได้ จำนวน 0 ในแม่แบบไม่ใช่ไม่มีสิทธิ์ และคัดลอกตำแหน่งแล้วไม่ได้อำนาจเจ้าของ
