## 5. ด่าน (`checkEligibility` ↔ `execute` ใช้กติกาเดียวกัน)

- **ถอด:** "มีรายการชำระแล้ว → ปฏิเสธ" (C-6)
- **เพิ่ม `checkEligibility`:** `receiptsToCreditNote[]` (เลขที่ · ชนิด · งวด · วันที่ · ช่องทาง · ยอด · ภาษี) · `creditToTransfer` (= Σ ใบ + 21-1103 + 21-5101 ในบัญชี) · `blocking` เหตุผลใหม่ด้านล่าง — หน้าหลังการขายใช้แสดงตารางและยอด (mockup กระดาน 2)
- **ยังปฏิเสธ (เหตุผลใหม่):** สัญญาเดิม**เคยปรับดิว** — predicate เดียว `hasRescheduleHistory(tx, contractId)` = มีใบเสร็จ `RESCHEDULE_FEE` ที่ยังมีผล **หรือ** `rescheduleAdvanceBalance > 0` **หรือ** มี JE `POSTED` ไม่ถูกลบ ไม่ `reversed` ที่ `metadata.contractId` = สัญญาเดิม และ `metadata.tag ∈ {6a, 6b}` หรือ `metadata.flow ∈ {reschedule-fee, reschedule-bundled, reschedule-final, reschedule-collect, reschedule-park-consume}` (ครอบทั้ง 6a แยกใบและ 6b รวมค่างวด — 6b ไม่มีใบ `RESCHEDULE_FEE`) — การเลื่อนนัดไม่มีทางย้อนกลับ และค่าธรรมเนียมเป็นบริการที่ใช้ไปแล้ว ⇒ "สัญญาเดิมมีการเลื่อนนัดชำระ — เปลี่ยนเครื่องผ่านระบบไม่ได้ ติดต่อผู้ดูแลระบบ" · สัญญาเดิมถูกกวาดลงรายได้ 42-1106 (`assertNoAdvanceExcessIncome`) · มีคำขอยกเลิกใบเสร็จ `VOID_RECEIPT` ค้างคิว · มีใบเสร็จ `EARLY_PAYOFF` (สัญญาไม่ ACTIVE อยู่แล้ว — ตาข่าย) · มีใบลดหนี้ค้างที่ไม่มีใบต้นทาง (ข้อมูลผิดปกติ)
- **ไม่ปฏิเสธ:** ใบเสร็จอายุเกิน 30 วัน (กฎ W-006 ของ void ไม่ใช้กับทางนี้ — ผู้ยืนยันรับผิดชอบ; เกิดได้เฉพาะ ผจก. ข้ามกรอบจากใบซ่อม) · ใบเสร็จช่องทางลิงก์ชำระ/เครดิต (ชนิดเดียวกัน)
- งวดบัญชี: `validatePeriodOpen` FINANCE วันนี้ (รายการทั้งหมดลงวันนี้) — ปิดแล้ว = 400 เดิมของระบบ

## 6. เปิดใช้สัญญาใหม่ → ใช้เครดิตอัตโนมัติ

- `ContractWorkflowService.activate(id)` commit แล้ว → ถ้า `parentContractId` ≠ null และ `creditBalance > 0` → เรียก `PaymentsService.applyCreditBalance(id, actorId)` (เส้นทางเดิม PR3: ใบเสร็จ/ใบกำกับภาษีช่องทาง `CREDIT_BALANCE` ต่องวด · 2A ตามกติกาตั้งลูกหนี้งวด ณ วันรับเงิน · ออกใบหลัง commit · LINE ตามกติกาใบงวด)
- `actorId` = ผู้ใช้ที่กดเปิดใช้ — `contracts.controller.ts` route `POST :id/activate` มี `@CurrentUser() user` อยู่แล้ว (บรรทัด 219) แต่เรียก `workflowService.activate(id)` โดยไม่ส่ง ⇒ เพิ่มพารามิเตอร์ท้ายไม่บังคับ `activate(id, actorId?: string)` และส่ง `user.id` จาก controller · ผู้เรียกอื่นที่ไม่ส่ง (spec/CLI) = ผู้ใช้ระบบ (`resolveSystemUserId` แบบเดียวกับ JournalAutoService) · ไม่มีผู้ใช้ระบบ = ข้ามการใช้เครดิต + Sentry (เครดิตค้าง ใช้ปุ่มมือ)
- ล้ม (งวดบัญชีปิด / P2034 / อื่น) → การเปิดใช้**ไม่ย้อน** · Sentry warning `action: 'defect-exchange-credit-autoapply-failed'` · เครดิตค้างบนสัญญา — พนักงานกด "ใช้ยอดเครดิต" มือ (ปุ่มเดิม) · `activate` คืน `creditApplied: { installments, receipts } | { failed: true, reason }`
- ใบเสร็จของการใช้เครดิตนี้: บรรทัดรอง "ชำระด้วยเครดิตจากการเปลี่ยนเครื่อง · สัญญาเดิม <เลข>" + แถว "ที่มาของเครดิต" ในส่วนการชำระเงิน (mockup กระดาน 3) — **ไม่มีคอลัมน์ใหม่ ไม่ใช้ `transactionRef`** (PDF พิมพ์ช่องนั้นเป็น "เลขอ้างอิง") · ตัดสินตอนพิมพ์ (`receipt-pdf.service`) ด้วยกติกาเดียว `resolveExchangeCreditSource(receipt)`: ใบเป็นช่องทาง `CREDIT_BALANCE` **และ** สัญญามี `parentContractId` **และ** มี JE `defect-exchange-credit-in` ของสัญญานี้ที่ยังมีผล (ยอด T) **และ** Σ ยอดของใบช่องทาง `CREDIT_BALANCE` ที่ยังมีผลของสัญญานี้ เรียงตาม `paidDate` แล้ว `receiptNumber` **จนถึงใบนี้** ≤ T + 0.01 ⇒ ใบนี้ถูกจ่ายด้วยเครดิตที่ย้ายมา (เครดิตเข้าสัญญาได้ทางเดียวก่อนเปิดใช้ และการใช้อัตโนมัติเกิดทันทีตอนเปิดใช้ จึงเป็นใบแรก ๆ เสมอ) · เกิน T = เครดิตจากจ่ายเกินทีหลัง ไม่แสดงบรรทัดรอง · เลขใบลดหนี้/ใบเดิมในกล่องเหลือง = `Receipt` ของสัญญาเดิมที่ `cnSource = 'DEFECT_EXCHANGE'` + `voidedReceiptId` ของมัน

## 7. ภาษีขาย

- ใบลดหนี้ลด 21-2101 ในเดือนที่เปลี่ยนเครื่อง (กระจก 2A ของงวดที่รับก่อนครบกำหนด — `tag REVERSAL` = "กลับรายการ" ใน ภ.พ.30) · งวดที่ครบกำหนดแล้ว: 2A ถูกกระจกโดยขั้น ค (เหมือนเดิม)
- **เครดิตที่ย้าย (ขั้น ง) ไม่ stamp `advanceVatPark`** — ต่างจากเงินรับล่วงหน้าทั่วไป (PR4 กติกา 14): ใบกำกับภาษีของเงินก้อนนี้ถูกยกเลิกด้วยใบลดหนี้แล้ว คำตอบ (ข) ให้ "ใช้เครดิตออกใบกำกับสัญญาใหม่" ⇒ ภาษีรับรู้เต็มตอนใช้เครดิต (2A ของสัญญาใหม่) และใบใหม่พิมพ์ภาษีเต็ม (ถ้า park ตอนย้าย ใบใหม่จะพิมพ์แถวหักภาษีสุทธิ 0 — G7/ต9) · ช่วงระหว่างเปลี่ยนเครื่องถึงเปิดใช้ เงินก้อนนี้ไม่มีภาษีขายค้าง — ปกติวันเดียวกัน/ไม่กี่วัน · **แจ้งฝ่ายบัญชีเพื่อทราบ** (เจ้าของคุยเอง)
- เงินของลูกค้าอื่นที่ย้าย (ขั้น ข) กลับภาษีที่พักไว้ทั้งก้อน (p) ด้วยเหตุผลเดียวกัน

## 8. เอกสาร (ตาม mockup — เคาะ 17/10)

- **ใบลดหนี้** (`receiptType CREDIT_NOTE` · `cnSource DEFECT_EXCHANGE`): หัว "ใบลดหนี้" · pill "อ้างอิงใบเสร็จเดิม <เลข>" · กล่องเหลือง "เอกสารนี้ออกเพื่อยกเลิกใบเสร็จรับเงิน / ใบกำกับภาษีเลขที่ <เลข> ลงวันที่ <วัน> เนื่องจากเปลี่ยนเครื่องตำหนิภายใน 7 วัน — ยอดตามใบเสร็จเดิมถูกกลับรายการทั้งจำนวน และโอนเป็นเครดิตของสัญญาใหม่ <เลขใหม่> (ใช้ชำระค่างวดของสัญญาใหม่ · ภาษีมูลค่าเพิ่มจะออกใบกำกับภาษีใหม่เมื่อใช้เครดิต)" · แถวรายการ "ลดหนี้ — <รายการของใบเดิม>" บรรทัดรอง "ตามใบเสร็จ <เลข> · เหตุผล: เปลี่ยนเครื่องตำหนิภายใน 7 วัน (ม.82/10 (3))" · ส่วน "ผลของการลดหนี้": เงินของลูกค้า X — ไม่คืนเงินสด · โอนเป็นเครดิต สัญญาใหม่ <เลข> · ใช้เครดิต ชำระค่างวดของสัญญาใหม่ (ใบกำกับภาษีใหม่) · ท้ายใบ "ใบลดหนี้ตามมาตรา 86/10" · **ไม่ส่ง LINE** · พิมพ์ได้จากหน้าใบเสร็จ/ประวัติการชำระ (ทางเดิมของใบลดหนี้) — เลขใหม่ของสัญญาอ่านจาก `Contract.parentContractId` ย้อนกลับ (ใบลดหนี้ผูกสัญญาเดิม)
- **ใบเสร็จ/ใบกำกับภาษีสัญญาใหม่ช่องทาง `CREDIT_BALANCE`**: ตามข้อ 6 (บรรทัดรอง + "ที่มาของเครดิต" + กล่องเหลือง "ชำระด้วยเครดิต X ที่โอนมาจากสัญญาเดิม <เลข> (ใบเสร็จเดิม <เลข> ถูกลดหนี้ด้วยใบลดหนี้ <เลข>) — ภาษีมูลค่าเพิ่มของค่างวดนี้ออกใบกำกับภาษีฉบับนี้ ไม่มีเงินสดรับเพิ่ม") · แถว "เปลี่ยนเครื่องจากสัญญา <เดิม> (ใบลดหนี้ <เลข>)" ในรายละเอียดสัญญา
- **กล่องยืนยันหลังการขาย** (`ExchangeActionDialogs` กิ่งสัญญาผ่อน): ตาราง "ใบเสร็จของสัญญาเดิมที่จะออกใบลดหนี้" (เลขที่ · รายการ · วันที่ชำระ+ช่องทาง · ยอด) + แถบ "เครดิตที่จะย้ายไปสัญญาใหม่ (ไม่คืนเงินสด) X บาท" · bullet ใหม่ 2 ข้อ (ใบลดหนี้ทุกใบ ไม่ส่ง LINE · เงินย้ายเป็นเครดิต ไม่คืนเงินสด ธนาคารไม่ขยับ) + ข้อเดิม "เปิดสัญญาใหม่…" ต่อท้าย "เมื่อเปิดใช้ ระบบใช้เครดิตชำระงวดที่ 1 ทันทีและออกใบเสร็จ/ใบกำกับภาษีใหม่" · ไม่มีใบเสร็จ = กล่องเหมือนวันนี้ทุกประการ · ข้อมูลจาก `checkEligibility` (ข้อ 5) ผ่าน `after-sales` lookup/outcomes ที่มีอยู่
- ไทม์ไลน์เคส: event ยืนยันระบุ "ใบลดหนี้ N ใบ · เครดิต X ย้ายไปสัญญา <ใหม่>"
