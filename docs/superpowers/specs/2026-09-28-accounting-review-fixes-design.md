  ```
  T = installmentTotal, V = vatPerInst (computeInstallmentBreakdown)
  Vp(x) = ROUND_HALF_UP(V × x / T)                      ← สูตรเดียวกับ computeCnBreakdown
  ใบสุดท้ายของงวด: instVat = V − ΣVAT ของใบก่อนหน้า      ← กติกา "ใบสุดท้ายรับส่วนที่เหลือ"
  ใบอื่น:          instVat = Vp(cleared − advOut)
  advVat = ROUND_HALF_UP(advIn × 7/107)
  เก็บ: amountBeforeVat, vatAmount, roundingAmount = overpay − underpay
  ต้องเป็นจริงเสมอ: amountBeforeVat + vatAmount + roundingAmount + feeNet = amount
  ```
- **ตัวเลขทอง:** จ่าย 6,079 → 5,681.00 / 397.67 / ปัดเศษ 0.33 · แบ่งจ่าย 3,079 แล้ว 2,999.67+0.33 → VAT 201.43 และ 196.24
- **PDF:** เพิ่มแถว "ปัดเศษ (ไม่อยู่ในฐานภาษี)" + บรรทัดในสรุปยอด · `documentVatPortion = total − fee − rounding`
- **ใบลดหนี้ตอนยกเลิกใบเสร็จ:** copy ตัวเลขทุกบรรทัดจากใบที่ยกเลิก (ปัจจุบันยอดทั้งก้อนกลายเป็นฐาน VAT และแถวค่าปรับหาย —
  ใบเสร็จ 3,050 = ค่างวด 3,000 + ค่าปรับ 50 แสดง VAT 196.26 แต่ใบลดหนี้แสดง 199.53)
- **เงื่อนไขก่อนหน้า:** X5 (auto-allocate ออกใบหลัง commit + ส่งเลข JE) · ใบเสร็จปิดยอดก่อนกำหนดต้องผูก JE ของ JP4
