# หลักฐานไฟล์ต้นทางก่อนย้าย Tooltify

ตรวจไฟล์แบบอ่านอย่างเดียววันที่ 21 พฤศจิกายน 2026 เวลา Asia/Bangkok จากรายชื่อไฟล์ขายและไฟล์ snapshot ที่ระบุให้ตรวจ 20 พาธ พบ 16 SHA-256 ต่างกัน แบ่งเป็นรายงานขาย 8 ไฟล์และ snapshot 8 ไฟล์ เลขแถวในเอกสารนี้อ้างถึงแถว Excel แบบเริ่มที่ 1 ในชีต `Worksheet` ช่วงรายงานมาจากชื่อไฟล์ วันที่จริงมาจากตารางรายละเอียด

การนำเข้าจริงยังอยู่ในสถานะ **UNRESOLVED** ยังไม่มีหลักฐานอนุมัติสาขาและเวลาตัดระบบ ชุดรายงานขาย canonical ช่วงยอดขายศูนย์ หรือวิธีจัดการข้อยกเว้นรายแถว เอกสารนี้บันทึกผลตรวจและหลักฐานที่ขาด ใช้ตรวจซ้ำได้จากชื่อไฟล์และ SHA-256

## เหตุการณ์ที่เปลี่ยนยอดและงานค้าง

รายงานขายฉบับล่าสุดมีหัวรายการจ่ายเครดิต ตัดสต๊อกทำสัญญาไฟแนนซ์ เบิกอะไหล่ และเคลม ที่ประกาศ 0 แถวและอ่านได้ 0 แถว ไม่พบตารางคืนหรือยกเลิกเฉพาะในแปดฉบับที่ตรวจ ขอบเขตรายงานคืนและยกเลิกยัง **UNRESOLVED** ต้องเทียบทะเบียนเหตุการณ์กับบิลเดิมก่อนรับรองยอดสุทธิหรือเริ่ม final apply หากพบเหตุการณ์ที่เปลี่ยนยอด ให้เพิ่มการตัดสินใจระดับเหตุการณ์และหลักฐานผูกบิลในงานประวัติ

งานค้างเฉพาะ Tooltify ยัง **UNRESOLVED** ได้แก่ สัญญาที่ยังผ่อน เงินจอง เครดิตลูกค้า งานซ่อม/เคลม และเอกสารรับประกัน ต้องสำรวจจำนวน ยืนยันผู้รับช่วง และจัดแนวทางเก็บหรือย้ายแยกก่อนเลิกใช้ Tooltify

## บันทึกหลักฐานในชุดนำเข้า

ส่งไฟล์ที่ต้องการตรวจเป็นพาธทีละไฟล์ให้ `npm run import:tooltify-cutover --workspace=@installment/api -- inspect --out-dir <dir> <file.xlsx> ...` เก็บ `inspection.json` และ `inspection.csv` ในพื้นที่จำกัดสิทธิ์ รายการเลือกสต๊อก รายการขาย ช่วงยอดศูนย์ หรือการตัดซ้ำต้องผูกกับ SHA-256 เลขแถว เหตุผล และหลักฐานที่ตรวจย้อนกลับได้ `hashSourceDecisions` ผูกบัญชีการตัดสินใจกับ manifest ตามเนื้อหา JSON หากต้นทางเปลี่ยน ให้ตรวจไฟล์และยืนยันหลักฐานใหม่
