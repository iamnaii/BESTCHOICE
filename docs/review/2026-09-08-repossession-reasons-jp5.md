# คืนเครื่อง: เหตุผล, คำอธิบาย JP5 และเงื่อนไขบันทึก

## ปัญหาและผลลัพธ์

หน้าคืนเครื่องแสดงยอดส่วนต่างราคาประเมินเทียบยอดปิดกับยอดกำไร/ขาดทุนใน JP5 โดยชื่อเดิมทำให้สับสน ไม่แสดงเงินรับล่วงหน้าที่หักจากยอดปิด และปุ่มยืนยันที่ถูกปิดใช้งานไม่มีเหตุผลอยู่ใกล้ปุ่ม

- เพิ่มตัวเลือกเหตุผลคืนเครื่อง: ไม่สามารถผ่อนต่อ, ไม่ประสงค์ใช้งานต่อ, รับคืนหลังบอกเลิกสัญญา และอื่น ๆ โดยข้อสุดท้ายต้องระบุรายละเอียด
- ส่งรหัสเหตุผลแยกจากหมายเหตุ บันทึกชื่อเหตุผลในหมายเหตุของรายการ และรหัส/ชื่อใน audit พร้อมผู้ทำรายการ รองรับ client เดิมที่ไม่ส่งรหัสเหตุผล
- คำอธิบายราคาประเมินต่างจากตารางเกินเกณฑ์ยังต้องกรอกเอง การเลือกเหตุผลไม่ทดแทนข้อกำหนดนี้
- แสดงเงินรับล่วงหน้าที่หักออกก่อนยอดปิดสัญญาสุทธิ และแยกชื่อส่วนต่างราคาประเมินเทียบยอดปิดจากกำไร/ขาดทุนจากรายการยึดคืน
- เปลี่ยนหัวรายการบัญชีเป็น “รายการบัญชีคืนเครื่อง (JP5)” พร้อมแสดงสถานะโหลดผิดพลาดและปุ่มลองใหม่
- แสดงสาเหตุที่ยังยืนยันไม่ได้ติดกับปุ่ม พร้อมลิงก์สัญญาเมื่อไม่ผ่านเงื่อนไขสถานะ รอผล preview ล่าสุดที่ลงบัญชีได้และสมดุลก่อนเปิดปุ่ม

## ความหมายของตัวเลขในภาพผู้ใช้

ส่วนต่างเชิงบริหาร −1,000.00 = ราคาประเมิน 16,717.97 − ยอดปิดสุทธิ 17,717.97

ยอด 18,431.97 เป็นขากำไรจากรายการยึดคืนใน JP5 ที่ภาพแสดง: 16,717.97 + เงินพัก 1,714.00 ภาพนี้ไม่มีบรรทัดเครดิตตัดลูกหนี้ จึงเพิ่มคำอธิบายให้ตรวจประวัติบัญชีประกอบ ยังไม่ได้ตรวจยอด GL ของสัญญาจริงเพื่อยืนยันสาเหตุที่ไม่มีบรรทัดดังกล่าว ตัวเลขนี้เป็นเฉพาะขากำไร/ขาดทุนยึดคืน ไม่ใช่ผลรวมรายได้และค่าใช้จ่ายทั้งหมดของ JP5

ระบบยังใช้เงื่อนไขบอกเลิกสัญญาที่ตั้งไว้เดิม สัญญาที่ยังไม่ผ่านเงื่อนไขจะบันทึกไม่ได้ทั้ง UI และ API ไม่มีการเปลี่ยนสถานะสัญญาจริง ส่งหนังสือบอกเลิก หรือแก้สูตรลงบัญชี JP5 ในงานนี้

- Web overlay และหน้ารายการยึดคืน: 20 tests ผ่าน รวมเหตุผลบังคับ, OTHER, ราคาประเมินต่างเกณฑ์, retry, preview หาย/ไม่สมดุล และกลับมาใช้ค่าที่เคยอยู่ใน cache

- Browser กับ service และ PostgreSQL จำลอง: สัญญาที่ถูกบล็อกไม่มี UI POST, API ตอบ 400 และไม่เขียนข้อมูล; สัญญาที่พร้อมยืนยัน POST สำเร็จหนึ่งครั้ง
