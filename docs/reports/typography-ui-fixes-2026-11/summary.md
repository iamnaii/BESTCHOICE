# ผลแก้หน้าตาตัวอักษรตามที่เจ้าของเคาะ — ก่อนแก้ / หลังแก้ (2026-11)

รายงานนี้วัดซ้ำหลังแก้ 4 เรื่องที่เจ้าของเคาะท้ายรายงานตรวจสเกลตัวอักษร

ตัวเลขทุกตัวมาจาก `findings.json` ในโฟลเดอร์นี้ (สร้างด้วย `node tools/typography-audit/report.mjs`)

**อ่านอย่างไร**

- **ก่อนแก้** = ผลวัดชุด "หลังเปลี่ยนฟอนต์" ของรายงานตรวจ (หลังบ้าน commit `f2f9977b8` · หน้าร้าน `e504094cd`) — โค้ดเท่ากับ main ก่อนเริ่มแก้
- **หลังแก้** = งานชุดนี้ทั้งหมด (รอบ 2 + รอบ 3) วัดทั้งระบบรอบเดียว — หลังบ้านที่ commit `d572fc029` · หน้าร้านที่ `8a54651d7` (รอบ 3 ไม่แตะหน้าร้าน) — ไม่เอาผลวัดแยกบางหน้ามาประกบ
  (ลองแล้วพบว่าการวัดแยกบางหน้าทำให้เมนูซ้ายแสดงต่างจากการวัดทั้งระบบ ตัวเลขเพี้ยน)
- วัดด้วยเครื่องมือและคำสั่งชุดเดิม: ทุกหน้า × จอ 1440 / 390 / 320 px × ธีมสว่าง/มืด (หน้าร้านมีแต่ธีมสว่าง) × เจ้าของ (owner) / พนักงานขาย (salesA)
- จับคู่เทียบได้ **2,043 ชุด** เท่ากันทั้งสองฝั่ง และสถานะของทุกหน้า (วัดได้ / ถูกพาไปหน้าอื่น / หน้าเอกสาร) ตรงกันทุกชุด

## แก้อะไรไปบ้าง

1. **ป้าย/ชิปคำสั้น** — ป้ายสถานะที่ใช้ทั้งระบบ (เช่น "ใช้งาน" "ไม่ใช้งาน" "เปิดใช้งาน") ห้ามขึ้นบรรทัดใหม่ · ชิปหน้าหลังการขาย ("สัญญาผ่อน" "รับเรื่องแล้ว"
   ฯลฯ — หน้านี้วาดชิปเอง จึงแก้แยก) · ป้ายที่ข้อความยาวได้ (ชิปเคสค้าง "ส่งศูนย์ N วัน (เกณฑ์ 14 วัน)" · ป้ายรับเครื่องคืนหน้าสัญญา ·
   ป้ายชื่อแม่แบบ SMS / ผู้ติดต่อ / โปรโมชันในแชท) ถ้ายาวเกินกรอบตัดท้ายด้วย "…" และแตะค้าง/ชี้เมาส์เห็นข้อความเต็ม · ป้ายแท็กบนการ์ดสินค้าหน้าร้าน ("ประกันร้าน 60 วัน") อยู่บรรทัดเดียว ถ้ายาวเกินกรอบตัดท้ายด้วย "…" ·
   ปุ่ม "เปิดใช้งาน/ซ่อนผู้จัดจำหน่าย" หน้าผู้จัดจำหน่ายไม่ขึ้นบรรทัดใหม่
2. **หัวตาราง** — หัวคอลัมน์ของตารางกลางและปุ่มเรียงลำดับ ห้ามขึ้นบรรทัดใหม่ ตารางที่กว้างเกินให้เลื่อนในกรอบของตาราง · แก้ตารางที่เขียนเองด้วย
   (ตารางสิทธิ์ `/settings/access` · บทบาทบัญชี · รายละเอียดเอกสารรายจ่าย · รายงานหัก ณ ที่จ่าย · ตารางหลังการขาย) · ปุ่มเรียงหัวตารางบนจอใหญ่สูง 32px ·
   หน้ารายการสินค้าขยาย 3 คอลัมน์ที่ล็อกความกว้างไว้ ให้หัวคอลัมน์กับลูกศรเรียงพอดี
3. **หัวข้อหน้า `/landing`** ระยะบรรทัด ×1.11 → ×1.3 (4 หัวข้อ) · ป้าย **"ใบเสร็จ"** ในไลน์ลูกค้า (หน้าประวัติชำระ) ตัว 10px → 12px
4. **ปุ่ม/ลิงก์ที่เล็กกว่าเกณฑ์** — เช่น ลิงก์ "กลับ…" · ปุ่ม "แก้ไข" หน้าตั้งค่า (รวมหน้าตั้งค่าดอกเบี้ย) · "แสดงอีก N งวด" ในไลน์ลูกค้า ·
   ปุ่ม "ตามรุ่น/ตามหมวด" หน้าแรก · ขยายพื้นที่กด ไม่ขยายตัวอักษร · ส่วนใหญ่เลย์เอาต์ไม่ขยับ (ใช้ขอบติดลบเท่ากับที่ขยาย) ·
   **ที่สูงขึ้นจนเห็นได้** (ไม่มีขอบติดลบเพราะไม่มีที่ให้ทับ): ปุ่มแบบกล่องบนมือถือ (ปุ่มหน้าแรก 36 → 44px · แท็บหน้าสินค้า 39 → 44px ·
   ปุ่มซ่อน/เปิดผู้จัดจำหน่าย) · รายการข้อผิดพลาดในฟอร์มบันทึกทรัพย์สิน (ทุกบรรทัดสูง 32px จอใหญ่ / 44px มือถือ — กล่องสูงขึ้นราว 60%) ·
   ลิงก์ "ล้างชื่อผู้ขาย" (มือถือ +~22px) · ลิงก์ "แสดงอีก N งวด" ในไลน์ลูกค้า (17 → 44px) · ลิงก์รหัสทรัพย์สินในการ์ดมือถือ ·
   หัวหน้ารายละเอียดผู้ใช้บนมือถือ — เจ้าของรับไว้ (รอบ 3 ข้อ 2)
