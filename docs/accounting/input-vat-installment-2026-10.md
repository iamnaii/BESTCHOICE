# ภาษีซื้อของเครื่องที่ขายผ่อน — สมุดไฟแนนซ์เคลมวันเปิดสัญญา (ก้อน 5 · ตุลาคม 2569)

ที่มา: คำตอบฝ่ายบัญชี 05/10/2569 ข้อ 2.1–2.5 และคำตัดสินเจ้าของกิจการ 2026-10-05 (เปิดบัญชี 42-1108 · ผู้มีสิทธิ์ · การเปลี่ยนเครื่อง · สิทธิ์เห็นยอด)

## สรุปคำตอบที่นำไปทำ

| ข้อ | คำตอบ | ทำอย่างไรในโปรแกรม |
|---|---|---|
| 2.1 เครื่องที่เคลมได้ | ซื้อจากผู้จัดจำหน่ายที่จด VAT และใบรับของอ้างใบกำกับภาษี (หรือใบกำกับตามมาภายหลัง) | ตอนรับของโปรแกรมเก็บ "ภาษีซื้อต่อเครื่อง" ไว้ทุกเครื่อง · เครื่องเคลมได้เมื่อยอดนี้ > 0 **และ** ใบรับของมีใบกำกับภาษี (รับด้วยใบกำกับ หรือบันทึกใบกำกับภายหลัง) |
| 2.2 แบ่ง VAT ของใบสั่งซื้อ | ตามสัดส่วนราคา (ตัวอย่าง A 686 / B 343 จาก 1,029) | สูตรปัดสะสมเดียวกับต้นทุน — รวมทุกเครื่องแล้วเท่ายอด VAT บนใบสั่งซื้อพอดี |
| 2.3 เดือนที่เคลม | เดือนที่ขายผ่อน · ไม่จำกัดอายุใบกำกับ | ลงรายการวันเปิดสัญญา · แสดงอายุใบกำกับ และขึ้นป้ายเตือนเมื่อเกิน 6 เดือน **ไม่บล็อก** |
| 2.4 รายการบัญชี | แบบ ก | `Dr 11-4101 ภาษีซื้อ / Cr 42-1108 รายได้อื่น-ภาษีซื้อของสินค้าที่ขายผ่อน` (สมุดไฟแนนซ์) |
| 2.5 ยกเลิกสัญญา | กลับรายการวันยกเลิก · ขายใหม่เคลมใหม่ | รายการถูกกลับอัตโนมัติพร้อมรายการอื่นของสัญญา · เครื่องกลับหน้าร้าน · เปิดสัญญาใหม่ = เคลมใหม่ |
| บัญชี | เจ้าของ: เปิด **42-1108** ใหม่ ไม่ฟื้น 42-1106/42-1107 | เพิ่มในผังพร้อม deploy |

## ตัวอย่าง (ตัวเลขจากคำถามข้อ 2.2)

ใบสั่งซื้อจากผู้จัดจำหน่ายที่จด VAT: เครื่อง A 9,800 + เครื่อง B 4,900 = 14,700 · VAT 7% = 1,029 → ภาษีซื้อต่อเครื่อง A 686.00 · B 343.00

- ขายผ่อนเครื่อง A วันที่ 5 ต.ค. 2569 → `Dr 11-4101 686.00 / Cr 42-1108 686.00` ลงวันที่ 5 ต.ค. 2569
- เครื่อง B ยังไม่ขาย → ไม่มีรายการ (เคลมเมื่อขายผ่อน · ขายสด/ไฟแนนซ์นอก = ไม่เคลม)
- ยกเลิกสัญญาเครื่อง A วันที่ 20 ต.ค. → `Dr 42-1108 686.00 / Cr 11-4101 686.00` ลงวันที่ 20 ต.ค. · ขายผ่อนใหม่ → เคลม 686.00 อีกครั้งลงวันเปิดสัญญาใหม่

## ใบกำกับภาษีที่มาหลังรับของ

1. รับของด้วยใบส่งของ (หรือไม่มีเอกสาร) → เปิดสัญญาได้ตามปกติ สัญญาแสดงสถานะ **"รอใบกำกับภาษี"** พร้อมยอดที่จะเคลม — ยังไม่ลงบัญชี
2. เมื่อได้ใบกำกับ เจ้าของ / ผู้จัดการสาขา / ฝ่ายบัญชี บันทึกเลขที่ + วันที่ (รูปไม่บังคับ) ที่ใบรับของในหน้าใบสั่งซื้อ → โปรแกรมเคลมย้อนให้ทุกสัญญาที่รออยู่ **ลงวันเปิดสัญญา**
3. ใบกำกับที่**ลงวันที่หลังวันเปิดสัญญา** → ลงรายการวันที่ในใบกำกับ (ไม่เคลมก่อนวันที่ใบกำกับ — เจ้าของยืนยัน 06/10/2569)
4. ถ้างวดของเดือนที่จะลง (วันเปิดสัญญา หรือวันที่ในใบกำกับ) ปิดไปแล้ว → ลงวันที่บันทึกใบกำกับแทน และฝ่ายบัญชีได้รับงาน (Todo) ระบุเลขสัญญา / ใบรับของ / รายการ เพื่อพิจารณาปรับปรุงหรือยื่นเพิ่มเติม — โปรแกรมไม่ลงรายการปรับปรุงเอง
5. บันทึกใบกำกับได้ครั้งเดียว แก้ได้เฉพาะเจ้าของหรือฝ่ายบัญชี (แก้แล้วเลข/วันที่ในรายการบัญชีที่เคลมไว้เปลี่ยนตาม) · เลขที่ซ้ำกับใบรับของอื่นของผู้จัดจำหน่ายเดิม = เตือนบนจอ ไม่บล็อก · ใบกำกับที่เก่ากว่า 365 วันบันทึกไม่ได้ (ด่านเดียวกับตอนรับของ — ถ้าเจอจริงแจ้งฝ่ายบัญชี)

## กรณีที่ไม่เคลม (การ์ดบนสัญญาบอกเหตุผล · ไม่ส่งงานแจ้ง)

- ผู้จัดจำหน่ายไม่จด VAT / บิลเงินสด (ภาษีซื้อต่อเครื่อง = 0)
- เครื่องที่ไม่มีใบรับของ: ยอดยกมาจาก Tooltify · เครื่องที่เพิ่มด้วยมือ
- เครื่องมือสองรับซื้อ / รับเทิร์น
- เครื่องที่รับเข้าก่อนโปรแกรมเริ่มเก็บภาษีซื้อต่อเครื่อง (ไม่ลงย้อนหลัง)
- **เครื่องเดิมที่กลับมาขายผ่อนอีกครั้ง** (ยึดคืนแล้วขายใหม่ · เครื่องเดิมจากการเปลี่ยนเครื่อง) ขณะที่สัญญาเดิมยังเคลมอยู่ (ไม่ได้ถูกยกเลิก) — ใบกำกับใบเดียวเคลมได้ครั้งเดียว การ์ดบอกเลขสัญญาที่เคลมไว้
- ของแถมในสัญญา · ขายสด · ไฟแนนซ์นอก

## ผู้เห็นตัวเลขภาษีซื้อ

เจ้าของ · ผู้จัดการการเงิน · ฝ่ายบัญชี เท่านั้น — ผู้จัดการสาขาเห็นเฉพาะสถานะใบกำกับ (มี / รอ / ไม่มี VAT) และบันทึกใบกำกับได้แต่ไม่เห็นยอด · พนักงานขายเห็นเฉพาะสถานะ (บันทึกไม่ได้)

## รายงาน ภ.พ.30

หน้า "VAT (ภ.พ.30)" แสดงภาษีซื้อแยกสองก้อน: **ภาษีซื้อค่าใช้จ่าย** และ **ภาษีซื้อเครื่องขายผ่อน** พร้อมตารางรายสัญญา (เลขรายการ · ใบรับของ · ใบกำกับ · อายุใบกำกับ · ยอด · กลับรายการ) · ไฟล์/รายงาน ภ.พ.30 ที่กดสร้างรวมรายการนี้ในหมวดภาษีซื้อด้วย (ฐานภาษี = ต้นทุนรวม VAT − VAT ของเครื่อง · ผู้ขาย = ผู้จัดจำหน่ายของใบรับของ)

## คำถามกลับฝ่ายบัญชี — เจ้าของกิจการตัดสินแล้ว 06/10/2569 (แจ้งฝ่ายบัญชีเพื่อทราบ)

1. **เปลี่ยนเครื่อง (เครื่องเดิมกลับหน้าร้าน):** นโยบายขาย — ลูกค้าต้องปิดยอดก่อนจึงทำสัญญาผ่อนใหม่ได้ ไม่มีการเปลี่ยนเครื่องกลางสัญญา จึงไม่เกิดกรณีต้องกลับรายการภาษีซื้อของเครื่องเดิม — **โปรแกรมปิดเมนูเปลี่ยนเครื่องแบบมีราคาแล้ว (06/10/2569)** ยื่น/อนุมัติใหม่ไม่ได้ (คำขอที่ค้างอยู่ปิดด้วยการปฏิเสธ · คำขอที่อนุมัติไว้ก่อนปิดคงพฤติกรรม "ไม่กลับรายการ" ไว้)
2. **เครื่องจากใบสั่งซื้อที่ถูกตัดสินค้าก่อนเข้าคลัง:** เครื่องที่ตรวจไม่ผ่าน = ตีกลับผู้จัดจำหน่าย (ไม่มีรายการบัญชี ตามคำตอบข้อ 8 ของ 30/09) จึงไม่มีกรณีตัดสินค้าก่อนเข้าคลัง — โปรแกรมปิดการขอตัดสินค้าของเครื่องจากใบสั่งซื้อที่ยังอยู่ในคิวรอถ่ายรูปแล้ว (ต้องตีกลับผู้จัดจำหน่าย) · "ไม่มีรายการ + งานแจ้งฝ่ายบัญชี" เหลือเครื่องที่ไม่มีใบรับของ (ยอดยกมา / เพิ่มด้วยมือ) และเครื่องจากใบสั่งซื้อที่ถูกเปลี่ยนสถานะออกจากคิวด้วยมือ · มัดจำส่วนของเครื่องที่ตีกลับยังค้าง `S11-4201` (ประเด็นมัดจำค้างที่รอเจ้าของ)
3. **ยอดยกมา Tooltify** ไม่มีภาษีซื้อต่อเครื่อง → ไม่เคลม — เจ้าของยอมรับ · ต้นทุนเครื่องยกมา = ราคาที่จ่ายผู้จัดจำหน่ายจริง (รวม VAT เมื่อผู้จัดจำหน่ายคิด VAT) · ยอดยกมาลง Dr S11-2001/2002 / Cr S32-1101 รายการเดียว
4. **ใบกำกับที่ลงวันที่หลังวันเปิดสัญญา** → ลงรายการวันที่ในใบกำกับ — เจ้าของยืนยัน
5. **เครื่องเดิมที่กลับมาขายผ่อนอีกครั้ง** ขณะสัญญาเดิมยังเคลมอยู่ → ไม่เคลมซ้ำ — เจ้าของยืนยัน
