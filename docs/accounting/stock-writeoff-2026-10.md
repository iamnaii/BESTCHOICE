# ตัดสินค้า — สูญหาย / เสียหาย / ตัดจำหน่าย / พบของคืน (ก้อน 3 · ตุลาคม 2569)

ที่มา: คำตัดสินเจ้าของกิจการ 2026-10-05 ("ให้เจ้าของอนุมัติทุกรายการ") และคำตอบฝ่ายบัญชี 29/09/2569 ข้อ ข6 ข6.2 ข7 · 30/09/2569 ข้อ 8

## ขั้นตอน

1. พนักงานขาย / ผู้จัดการสาขา (สาขาตัวเอง) หรือเจ้าของ ส่ง **คำขอตัดสินค้า** `SA-YYYYMMDD-NNNN` ระบุเหตุผล + หมายเหตุ + รูปหลักฐาน
   (เหตุผล "เสียหาย" บังคับรูปอย่างน้อย 1 รูป)
2. เหตุผล **สูญหาย / เสียหาย / ตัดจำหน่าย** → เครื่องถูกพักขายทันที (สถานะ "รออนุมัติตัดสินค้า") — ขาย / จอง / โอน / แก้สถานะไม่ได้
3. เจ้าของได้รับงาน (Todo) → เปิดเมนู คลังสินค้า › ตัดสินค้า → เห็นรูป · ที่มาของเครื่อง · รายการบัญชีที่จะลง → **อนุมัติ** หรือ **ไม่อนุมัติ** (ต้องมีเหตุผล 10–500 ตัวอักษร)
4. ไม่อนุมัติ หรือผู้ขอยกเลิกคำขอเอง → เครื่องกลับสถานะเดิมก่อนขอ (เช่น กลับไป "รอถ่ายรูป" ไม่ใช่ "พร้อมขาย" เสมอ)

## รายการบัญชี (สมุดหน้าร้าน · ลงวันที่อนุมัติ · ต้นทุน = `costPrice` ของเครื่อง ณ วันอนุมัติ)

| เหตุผล | ผลต่อเครื่อง | Dr | Cr |
|---|---|---|---|
| สูญหาย | ออกจากสต๊อก | `S53-1102` ขาดทุนสินค้าเสียหาย/สูญหายสาขา | `S11-2001` มือถือใหม่/แท็บเล็ต · `S11-2002` มือถือมือสอง · `S11-2003` อุปกรณ์เสริม (ตามหมวดเครื่อง) |
| ตัดจำหน่าย | ออกจากสต๊อก | `S53-1102` | `S11-200x` |
| เสียหาย (เครื่องยังอยู่) | คงในสต๊อก สถานะ "เสียหาย" | — ไม่ลง (ข7) จนกว่าจะขายหรือตัดจำหน่าย | — |
| พบของคืน | กลับเข้าสต๊อก | กลับรายการใบตัดเดิม: `S11-200x` | `S53-1102` |
| แก้ไขข้อมูล / อื่น ๆ | ไม่เปลี่ยน | — | — |

ตัวอย่าง: iPhone 15 ต้นทุน 10,700.00 (10,000 + VAT 7% จากใบรับของ) สูญหาย → `Dr S53-1102 10,700.00 / Cr S11-2001 10,700.00` ·
พบของคืนภายหลัง → `Dr S11-2001 10,700.00 / Cr S53-1102 10,700.00` และใบตัดเดิมถูกประทับว่ากลับรายการแล้ว

## กรณีที่ "ไม่มีรายการบัญชี" และฝ่ายบัญชีจะได้รับงาน

โปรแกรมเครดิต `S11-200x` **เฉพาะเครื่องที่เคยเดบิตเข้ามาก่อน** — ตรวจจากหลักฐาน 4 ทาง: ใบรับของที่ลงบัญชีแล้ว · รับซื้อ/รับเทิร์นมือสอง · รับเครื่องคืน/ยึด · เปลี่ยนเครื่อง.
เครื่องที่ **ไม่มี**หลักฐาน (ของยกมาจาก Tooltify ที่รอฝ่ายบัญชีตั้งยอด · เครื่องที่เพิ่มด้วยมือ · มือสองจากใบสั่งซื้อที่ยังรอถ่ายรูป) จะถูกตัดออกจากสต๊อก
**โดยไม่มีรายการบัญชี** และฝ่ายบัญชีได้รับงาน (Todo แท็ก `stock-adjustment-unbooked`) ระบุเครื่อง · ต้นทุน · เลขคำขอ · ที่มา เพื่อพิจารณาปรับยอดยกมาหรือลงรายการปรับปรุงเอง —
ระบบไม่ลงรายการให้ (คำตอบข้อ 8).

เครื่องที่ยอดรับเข้าในบัญชีไม่เท่าต้นทุนปัจจุบัน (มีคนแก้ต้นทุนด้วยมือ) → โปรแกรมลงที่ต้นทุนปัจจุบันและส่งสัญญาณเตือนให้ผู้ดูแลระบบ

## เอกสาร/ร่องรอยที่ตรวจย้อนได้

- แถวคำขอ: เลขที่ · เหตุผล · สถานะเดิม · ผู้ขอ · ผู้อนุมัติ/ไม่อนุมัติ/ยกเลิก + เวลา · เหตุผลที่ไม่อนุมัติ · ต้นทุนที่ลง · บัญชีสินค้า · มีหลักฐานรับเข้าหรือไม่ · ที่มา · เลขที่รายการบัญชี
- รูปหลักฐานเก็บในที่เก็บไฟล์ของระบบ (เปิดดูได้จากหน้าคำขอ)
- รายการบัญชีมี `metadata.requestNumber` และ `metadata.productId` · รายการกลับมี `reversesEntryId` ชี้ใบเดิม
- บันทึกการใช้งาน (AuditLog) `STOCK_ADJUSTMENT_REQUESTED / APPROVED / REJECTED / CANCELED`

## ที่ยังไม่ครอบคลุม (รอคำตอบ/คำสั่ง)

- ยอดยกมาของสินค้าที่มีอยู่ก่อนเริ่มใช้ (Tooltify) — ยังไม่ตั้ง ⇒ ตัดเครื่องกลุ่มนี้ = ไม่มีรายการ + แจ้งบัญชี
- เครดิตโน้ตจากผู้จัดจำหน่ายกรณีเคลมเครื่องเสีย — ตัดจำหน่ายลงขาดทุนเต็มจำนวนไปก่อน
- **คำถามถึงฝ่ายบัญชี:** เครื่องมือสองจากใบสั่งซื้อที่ยังรอถ่ายรูป (ยังไม่ลงรับเข้าและยังไม่ตั้งเจ้าหนี้) ถูกตัดสูญหาย/ตัดจำหน่าย — ปัจจุบันตัดโดยไม่มีรายการและแจ้งงานให้ฝ่ายบัญชี (ระบุเลขใบรับของ/ใบสั่งซื้อ) แต่เจ้าหนี้ของเครื่องนั้นไม่ถูกตั้ง ⇒ ถ้าจ่ายผู้จัดจำหน่ายเต็มใบ ส่วนนี้จะค้างเป็นมัดจำ `S11-4201` · ควรให้โปรแกรมลงรับเข้า (`Dr S11-2002 / Cr S21-1101`) ก่อนแล้วตัด (สุทธิ `Dr S53-1102 / Cr S21-1101`) หรือไม่
- งวดบัญชีของเดือนที่อนุมัติปิดแล้ว → อนุมัติไม่ได้ (ต้องให้ฝ่ายบัญชีเปิดงวดก่อน)
